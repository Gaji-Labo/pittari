# 差分チェック

実装後、`design-diff` が見本画像（Figma の書き出し画像、またはデザイン画像）と実装の描画結果を比べる。

## 合格の条件

差分は 2 つで測り、両方を満たせば合格とする。

- 配置のずれ: `--layout-tolerance`（既定 1px）以内。
  - Figma の URL から実装する場合は、Figma の各ノードと実装の要素を突き合わせた箱（位置と寸法）のずれで測る。
  - デザイン画像から実装する場合は、実装側の要素の辺（背景や枠のある要素は箱の辺、文字は字の外接矩形の辺）と、デザイン画像の近くにある同じ境界とのずれで測る。透明な入れ物や背景と同じ色の要素のように境界の見えない辺と、親要素に切り取られてはみ出した辺は、判定不能として数えない。デザインにあって実装に無い要素は辺では見つからないので、画素の差分に任せる。
- 画素の差分: 比較した画素のうち差分のある画素の割合 `diffRatio` が `--threshold`（既定 0.02）以下。

素材が提供されずプレースホルダーで実装した写真やアイコンは、見本画像と実装の両方の比較から外す。外した画素は `diffRatio` の分母にも分子にも入らない。

## 出力

比較のたびに `.design-diff/<selector>-<width>/` へ次のファイルが上書きされる。

| ファイル | 中身 |
| --- | --- |
| `design.png` | 見本画像 |
| `actual.png` | 実装の描画結果 |
| `diff.png` | 差分のある画素。比較から外した範囲は青で塗られる |
| `compare.png` | `design.png` `actual.png` `diff.png` を縮小して横に並べた画像。比較から外した範囲は青で塗られる |
| `summary.json` | 合否・`diffRatio`・差分のある画素の固まりの位置・比較から外した範囲（`excludedCssPx`） |
| `layout.json` | ノードごとの箱のずれ。Figma の URL から実装した場合だけ出る |
| `edges.json` | 実装側の要素の辺ごとのずれと判定不能の辺。デザイン画像から実装した場合だけ出る |

## 入力と出力の置き場所

`design-diff` と Stop hook は、入力と出力を次のとおりに扱う。

- `--metadata`・`--texts` で渡されたファイルは、`.design-diff/inputs/` の下にあるものだけを読む。それ以外の場所のファイルは、読まずにエラーで終える
- `--design` で渡されたファイルは、置き場所を問わず読む。PNG として読めないファイルは、中身を出さずにエラーで終える
- `.design-diff` とその中のディレクトリ、読むファイル（`runs.jsonl`・登録・`inputs` の下のファイル）がリンクのときは、読み書きせずにエラーで終える
- 書き出すファイルがリンクのときは、リンク先は変えず、リンクそのものを新しいファイルで置き換える
- `--out` に渡せるのは、英数字・`-`・`_` だけの名前。`sessions`・`inputs` は渡せない

置き場所を限る理由は、[ADR 0002](adr/0002-outside-sandbox-io.md) に書く。

## 撮影中の通信

`--url` には開発サーバーの URL を渡す。渡せるのは、ホスト名が `localhost`・`127.0.0.1`・`[::1]`・`*.localhost` の `http:` か `https:` の URL だけ。撮影中の Chrome は、`--url` のオリジン（ホスト名とポート）と、`--allow-domain` で渡したホストにだけ通信する。それ以外への通信は遮断し、遮断した外部のホストをリソースの種類（`font`・`image`・`script` など）と件数とともに出力する。`--url` と別のオリジンのローカルの宛先（別のポートの API サーバーなど）も遮断し、ホスト名とポートを「読み込めなかったローカルの宛先」に出す。ローカルの宛先は `--allow-domain` では許可できない。最初に開いたページが外部の宛先へ移ろうとしたときは、撮影せずにエラーで終える。`--allow-domain` には、スキーム・ポート・ワイルドカードを付けないホスト名を渡す。

`--allow-domain` を付けた `design-diff` の実行は、auto mode でも、プラグインの PreToolUse hook がユーザーの承認画面に回し、渡した宛先を並べて許可するかを尋ねる。同じセッションの間は、承認した宛先だけを使う実行では再び尋ねない。セッションを終えると承認を忘れ、`--resume` などで再開したセッションでは改めて尋ねる。

hook は、`design-diff` の名前を含むコマンドのうち、`design-diff` で始まり、記号を含まない語か引用符で囲んだ語だけが続く形のものだけを通す。`cd`・環境変数・`timeout` などを前に付けた形、`&&` などでほかのコマンドとつないだ形、変数やリダイレクトを含む形、`cat plugin/bin/design-diff` のように名前を含むだけのコマンドは拒否する。node が見つからないなどで hook が失敗したときは、Bash の実行を止める（Claude Code v2.1.295 以降）。

通信先を絞る理由と採らなかった案は、[ADR 0001](adr/0001-capture-network-restriction.md) に書く。

## 差分チェックの完走

`/design-to-code` を呼んだセッションでは、スキルの Stop hook が有効になる。settings.json への追記は要らない。スキルが登録したセレクタと幅の組のどれかが、合格も調整 3 回での打ち切りもしていないまま Claude Code が終えようとすると、hook が理由（未実行・未合格・合格後に未再実行）を返して終了を止める。

合格後に未再実行かどうかは、計測時と終了時の作業ツリーのハッシュ（HEAD と、コミットしていないファイルの中身から求める）を比べて決める。git で管理していないプロジェクトと、親のリポジトリが `.gitignore` などで除外しているディレクトリでは、合否と調整回数だけで判定する。前回止めたときから実行記録も作業ツリーも変わっていなければ、同じ理由では止めない。

Stop hook はサンドボックスの外で動く。登録はセッションごとに `.design-diff/sessions/<セッション ID>.json` へ、実行記録は `.design-diff/<selector>-<width>/runs.jsonl` へ残る。
